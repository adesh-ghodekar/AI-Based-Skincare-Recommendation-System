# AI-Based-Skincare-Recommendation-System
An AI-powered skincare recommendation system that analyzes facial skin images using Deep Learning to detect skin conditions and suggest personalized skincare products. The system also maintains user history to track skin improvement over time

# Project Overview
This project uses Machine Learning and Computer Vision techniques to analyze uploaded skin images and identify conditions such as acne. Based on the detected skin condition, the system recommends suitable skincare products.

The application is developed as a Flask web application with a SQLite database for secure user authentication and progress tracking.

# Features
👤 User Authentication

Secure login and registration using password hashing

📸 Skin Image Upload & Analysis

AI-based detection of skin conditions from images

🤖 Deep Learning Model

TensorFlow/Keras model for skin condition classification

🧴 Personalized Skincare Recommendations

Product suggestions based on detected skin condition

📊 Progress Tracking

Stores previous analysis results to monitor improvement

🗄️ Database Management

SQLite database for users and progress records

# Tech Stack
Language: Python

Backend: Flask

Machine Learning: TensorFlow, Keras, NumPy

Frontend: HTML, CSS, Jinja Templates

Database: SQLite

Libraries: OpenCV, Pandas, Werkzeug
